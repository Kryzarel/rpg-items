# RPG Items

A framework for implementing items and inventories in C# and Unity.

## YouTube Tutorial

Watch the [RPG Items Playlist](https://www.youtube.com/watch?v=uNVLQ2CuO_8&list=PLm7W8dbdflogsSk73wzTDgkHM-vDDjvMT) on YouTube for a full, in-depth explanation of the usage and step-by-step implementation of the codebase.

## Installation

### Dependencies

[RPG Items](https://github.com/Kryzarel/rpg-items) requires the [C# Utilities](https://github.com/Kryzarel/c-sharp-utilities) package, for stable sorting algorithms and some other miscellaneous utilities.

### Install via Git URL

1. Navigate to the Packages folder in your Unity project and open the `manifest.json` file.
2. Add these lines:
	-	```json
		"com.kryzarel.c-sharp-utilities": "https://github.com/Kryzarel/c-sharp-utilities.git",
		```
	-	```json
		"com.kryzarel.rpg-items": "https://github.com/Kryzarel/rpg-items.git",
		```

Alternatively, you can open the Package Manager window in Unity, click the "+" button on the top left, click "Install from git URL" and and paste each of the URLs shown above.

### Updating

In the Package Manager window, select the "In Project" tab, select the package you wish to update, click the "Manage" dropdown button, and then click "Update".

### Install manually

1. Clone or download the [C# Utilities](https://github.com/Kryzarel/c-sharp-utilities) and the [RPG Items](https://github.com/Kryzarel/rpg-items) repositories.
2. Copy/paste or move both repository folders directly into your project's Packages folder or into the Assets folder.

To update a manual installation, delete the existing folders and do the manual installation process again.

## Note

RPG Items provides two example UIs, but they are not included in the main package. You can find them as separate packages: [RPG Items UI](https://github.com/Kryzarel/rpg-items-ui) or [RPG Items UI ARC Raiders](https://github.com/Kryzarel/rpg-items-ui-arc-raiders).
